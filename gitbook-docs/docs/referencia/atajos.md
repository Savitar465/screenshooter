# Atajos de teclado

Los marcados como **global** funcionan aunque QAflow no tenga el foco, y se configuran en
[Ajustes](../configuracion/capturas-y-atajos.md).

## Navegación

| Atajo | Acción |
|-------|--------|
| `Ctrl+1` … `Ctrl+5` | Casos · Plan · Ejecución · Historial · Bugs |
| `Ctrl+6` | Issues |
| `Alt+←` | Volver (camino de vuelta) |
| `Ctrl+,` | Ajustes |
| `Ctrl+Q` | Salir |

## Casos

| Atajo | Acción |
|-------|--------|
| `Ctrl+N` | Nuevo caso |
| `Ctrl+F` | Buscar caso |
| `Ctrl+D` | Duplicar caso |
| `Ctrl+Z` | Deshacer el último borrado |
| `Ctrl+O` | Importar casos |

## Ejecución

| Atajo | Acción |
|-------|--------|
| `F5` | Ejecutar el caso o plan elegido en la barra |
| `Ctrl+Alt+Espacio` | Pausar o reanudar |
| `P` / `F` / `B` / `S` | Pasa / Falla / Bloqueado / N/A |
| `Retroceso` · `Alt+←` · `Alt+→` | Moverse por los pasos |
| Clic en un paso | Ir a ese paso |
| `F11` | Modo foco (`Esc` sale) |
| `Ctrl+Alt+P` | **Global** · Pasa el paso y avanza |
| `Ctrl+Alt+F` | **Global** · Falla el paso y avanza |
| `Ctrl+Alt+A` | **Global** · Vuelve al paso anterior sin tocar su veredicto |
| `Ctrl+Alt+D` | **Global** · Pasa al siguiente sin dar veredicto |
| `Ctrl+B` | Reportar bug |

## Evidencias

| Atajo | Acción |
|-------|--------|
| `Ctrl+Shift+S` | **Global** · Capturar pantalla (otra pulsación cancela la cuenta atrás) |
| `Ctrl+Shift+G` | **Global** · Iniciar o detener la grabación de GIF |
| `Ctrl+Shift+A` | Adjuntar archivos (o arrastrarlos a la ventana) |
| Clic en una miniatura | Abrir la evidencia a tamaño completo |
| `←` `→` (visor) | Evidencia anterior / siguiente |
| `Ctrl+E` (visor) | Anotar |
| `Ctrl+C` (visor) | Copiar al portapapeles |
